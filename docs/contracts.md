# 资料与既有接口约定

branches.py提供不可变完整行提交及独立refs，snapshot.py提供带字段目录的完整行快照，objects.py按正文SHA256寻址；tables.py在其上实现分块写时复制表、零拷贝克隆、读句柄与容量账，设计约定见docs/clone.md。资料中的base、dev、main为已有独立修订，仅作为冻结行内容，不代表已存在克隆能力。row_id在一张逻辑表中稳定唯一，字段ID不随名字变化，null为显式值，缺省仅作用于该快照物理缺席字段。容量按对象实际字节计，逻辑量是每张表可达对象集合的字节和，物理量是全体有效根可达对象并集的字节和；读句柄在保留期内也为根。本期只需报告回收资格，不实际清除对象。

资料均为合成，现有inspect读取并核对基础接口。
